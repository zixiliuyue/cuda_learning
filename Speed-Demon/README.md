## 🎯 面试核心方法论

### 性能问题排查六步法（面试必背）

```
发现问题
  ↓
1. 定义问题 → 现象、范围、影响、变化点（不要瞎猜！）
  ↓
2. 建立基线 → 应用层/系统层/运行时/依赖层指标
  ↓
3. 假设驱动 → CPU 高？内存高？延迟高？吞吐量上不去？
  ↓
4. 工具验证 → 监控 → trace → pprof cpu/heap/mutex
  ↓
5. 实施优化 → 架构层（最大收益）→ 应用层 → 微优化
  ↓
6. 复盘预防 → benchmark 验证 + 监控告警 + 故障手册
```

### 性能优化金字塔（优先级从高到低）

```
┌─────────────────────────────────────────┐
│ 架构层优化（10x - 100x 收益）          │
│ 加缓存、同步改异步、批量操作、减少依赖调用 │
├─────────────────────────────────────────┤
│ 应用层优化（2x - 10x 收益）             │
│ 算法优化、减少内存分配、并发优化、锁粒度 │
├─────────────────────────────────────────┤
│ 微优化（1.1x - 2x 收益）                │
│ 循环优化、内联、内存对齐、编译器优化      │
└─────────────────────────────────────────┘
```

| 问题现象 | 优先工具 | 关键命令 |
|---------|---------|---------|

## 💡 面试加分回答模板

### 谈方法论
> "性能优化最重要的是方法论。我的流程是：先通过监控明确问题范围，建立基线，用假设驱动排查，找到瓶颈后按架构→应用→微优化顺序解决，最后用 benchmark 验证，复盘加监控告警。"

### 谈权衡
> "性能优化本质是权衡：用内存换 CPU（缓存）还是 CPU 换内存（流式），用空间换时间还是时间换空间，用复杂度换性能，用一致性换性能。没有绝对的好，只有适合场景的选择。"

### 谈可观测性
> "性能优化的前提是可观测性。四个黄金指标（延迟、流量、错误、饱和度）必须有监控，再配合日志和链路追踪，出问题 5 分钟就能定位。"

## ⚠️ 性能优化常见误区（面试避坑）

1. ❌ **过早优化**：架构设计考虑性能，编码时不过度优化，出问题再精准优化
2. ❌ **只看平均延迟**：用户感知的是 P99/P999，不是平均值
3. ❌ **优化不存在的瓶颈**：先看热点占比，优先优化占比高的
4. ❌ **只优化 QPS 不看成本**：资源使用率也是性能指标的一部分

```
├── 案例层面：准备 3-5 个自己的优化故事（STAR 法则）
├── 深度层面：能讲清底层原理，不是只停留在用法
└── 延伸层面：能举一反三，从一个问题延伸到相关领域
```

**建议行动**：
- 把每个高频问题的答案写下来，至少 300 字
- 找人模拟面试，录下来回听自己的回答
- 每个问题都准备好：原理 → 案例 → 数据 → 思考

### 📖 优化故事准备（面试前 30 分钟）
准备 **3 个不同类型**的优化故事，用 **STAR 法则** 讲述：

**故事 1：CPU 优化**
- [ ] Situation：背景（什么服务，遇到什么问题）
- [ ] Task：目标（优化前 QPS/延迟，优化目标是什么）
- [ ] Action：做了什么（用什么工具，发现什么问题，怎么优化）
- [ ] Result：结果（优化后的数据，提升了多少，有什么沉淀）

**故事 2：内存优化**
- [ ] Situation：内存泄漏/GC 频繁的背景
- [ ] Task：要解决的问题
- [ ] Action：排查过程，工具使用，优化手段
- [ ] Result：内存使用率下降多少，GC 频率下降多少

**故事 3：并发优化**
- [ ] Situation：锁竞争/ goroutine 泄漏的背景
- [ ] Task：要解决的问题
- [ ] Action：怎么发现问题，怎么优化（分片/无锁/原子）
- [ ] Result：吞吐量提升多少，延迟下降多少

### 🚨 面试当天早上（15 分钟）
- [ ] 快速过一遍决策树（17_decision_tree/ 下的 3 个文件）

### 💯 面试中注意事项
1. **听到问题先别急着回答**，先想 3 秒钟，组织好逻辑
2. **用方法论回答**：先讲整体框架，再讲具体细节
3. **用数据说话**：优化了多少，提升了几倍，要有具体数字
4. **讲出思考过程**：不仅讲答案，还要讲你是怎么想到的
5. **诚实说不知道**：真不会就说这个场景没遇到过，但我会怎么排查
6. **引导面试节奏**：把话题往你准备好的方向引
