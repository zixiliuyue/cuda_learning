### 部署步骤（需要手动执行）

#### 第一步：上传文件到服务器

在 Windows 命令行中执行：

```bash
cd F:\code\cuda_learning\deploy_package

# 上传压缩包
scp qingtian.tar.gz sen@192.168.10.82:/opt/qingtian/

# 上传服务器端部署脚本
scp server_deploy.sh sen@192.168.10.82:/opt/qingtian/

# 输入密码：123
```

#### 第二步：SSH 登录服务器

```bash
ssh sen@192.168.10.82
# 输入密码：123
```

#### 第三步：执行部署脚本

```bash
cd /opt/qingtian
chmod +x server_deploy.sh
bash server_deploy.sh
```

脚本会自动完成以下操作：
- 检查并安装 Docker（如果需要）
- 解压项目文件
- 执行 `docker compose up -d --build`
- 检查服务状态
