# Python 10 大性能反模式总览

## 什么是反模式？

反模式（Anti-Pattern）是指在实践中反复出现但又低效、有问题或适得其反的解决方案。这些模式看起来像是正确的做法，但实际上会导致性能下降、内存泄漏、代码难以维护等问题。

## 10 大性能反模式

| 序号 | 反模式 | 主要问题 | 影响 |
|------|--------|----------|------|
| 01 | [GIL 陷阱](./01_gil_trap.md) | 多线程跑 CPU 密集任务反而变慢 | 性能下降 |
| 02 | [可变默认参数](./02_mutable_default.md) | 可变默认参数导致内存泄漏 | 内存泄漏、数据错误 |
| 03 | [闭包捕获大对象](./03_closure_leak.md) | 闭包捕获大对象导致无法释放 | 内存泄漏 |
| 04 | [循环 append 列表](./04_loop_append.md) | 循环 append 列表低效 | 性能下降 |
| 05 | [循环内访问全局变量](./05_global_var.md) | 循环内频繁访问全局变量 | 性能下降 |
| 06 | [ORM N+1 查询](./06_n_plus_one.md) | ORM 查询时产生 N+1 次数据库查询 | 性能急剧下降 |
| 07 | [无界缓存内存泄漏](./07_unbounded_cache.md) | 缓存无限制增长导致内存耗尽 | 内存泄漏、OOM |
| 08 | [无限创建线程](./08_thread_bomb.md) | 无限制创建线程导致资源耗尽 | 系统崩溃 |
| 09 | [异步代码中调用阻塞 IO](./09_blocking_async.md) | async 代码中调用阻塞函数 | 并发能力下降 |
| 10 | [过早优化](./10_premature_opt.md) | 过度优化导致代码复杂且未必更快 | 可维护性下降 |

## 如何使用本教程

1. 阅读每个反模式的 `.md` 文件，理解问题描述和修复方案
2. 运行对应的 `.py` 文件，观察性能对比
3. 在实际项目中避免这些反模式

## 运行示例

```bash
cd 09_anti_patterns
python 01_gil_trap.py
```

## 总结

性能优化的关键是：
1. **先测量，后优化** - 使用 profiling 工具找到瓶颈
2. **理解底层机制** - 了解 Python 的 GIL、内存管理等机制
3. **选择合适的工具** - 不同场景选择多进程、多线程或异步
4. **保持代码简洁** - 可读性优先，只在必要时优化
